HOW TO EDIT STABLE

Replace these four image files with your real project images:
- hero.jpg       = main/hero image
- process-1.jpg  = first process image
- process-2.jpg  = second process image
- final.jpg      = final design image

You can simply keep the filenames the same and replace the files.

Then open index.html and replace the placeholder paragraphs under:
1. The Challenge
2. The Design
3. Goal / Approach / Result
4. The Process captions
5. The Final Design caption
6. Reflection

No CSS changes are required just to swap photos or text.
